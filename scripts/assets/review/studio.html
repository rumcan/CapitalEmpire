Sprite studio

Every sprite is shown at the size the game draws it, and your pointer is a townsperson at the same scale (feet on the pointer): stand him at a door to check it. Smaller / Bigger change the sprite everywhere it is placed (the game reads the size when it reloads, no rebuild); an old building is shown as the new-art picture it is drawn as. A size past the picture's own pixels is allowed: the card warns, and a Rebuild upscales the picture (a little softer until higher-res art).
Click a frame to fix it: mirror it, use another frame (of any facing) in its place, or mark it as needing a new frame and drop the new picture in. Rebuild game sprites to put the fixes in the game. The strip on the right plays the walk as the game does (frames 1-8).
The lot lab runs in the game itself (the dev server of this checkout), so a lot is composed and drawn exactly as the game does: open it in its own tab
