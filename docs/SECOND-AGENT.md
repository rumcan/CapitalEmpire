## How to work without clashing
1. **Your own worktree per task**, cut from main, with the node_modules junction (from the repo root):
   `git -C .claude/worktrees/main-merge worktree add -b agent2/<task> "<repo>/.claude/worktrees/agent2-<task>" main` (use the
   absolute path: a relative path lands inside main-merge), then
   `cmd /c mklink /J .claude\worktrees\agent2-<task>\node_modules .claude\worktrees\main-merge\node_modules`.
   Branches are `agent2/*`; the lead's are `claude/*`.
2. **Landing on main** (main-merge is one working tree for both agents, so take turns):
   - take the lock: `mkdir "<repo>/.claude/merge-lock"` (it fails if the lead holds it: wait and retry later; never delete a lock you
     did not take);
   - in main-merge: `git status` must be clean apart from the owner's studio files (commit those first, see above);
     `git merge --no-edit agent2/<task>`; run the tests your change touches and `npx tsc --noEmit -p .`; `npm run build`
     (5174 is `vite preview` of main-merge's `dist/`: the owner sees it on reload);
   - release the lock: `rmdir "<repo>/.claude/merge-lock"`.
   - If a merge conflicts in a file that is not yours, abort it (`git merge --abort`), release the lock and ask the lead.
3. **Servers:** 5174 (the owner's game), 5179 (the owner's studio) and 5173 run from main-merge: never stop them. Serve your own
   worktree on 5190-5199 (`npx vite --host 127.0.0.1 --port 5191 --strictPort` in a terminal tab, then preview_start {url}).
   After changing the studio's server code, restart the 5179 studio from main-merge
   (`node scripts\assets\review\server.mjs --port 5179`): its edits are saved on disk, nothing is lost.
4. **RAM:** the dev PC is short of memory and the lead runs checks too: at most one build or full test run at a time, per-file
   tests otherwise (`npx esbuild tests/<f>.test.ts --bundle --platform=node --format=esm --loader:.webp=empty --loader:.png=empty
   --loader:.jpg=empty --outfile=output/tests/<f>.test.mjs && node --test output/tests/<f>.test.mjs`). The worker PC
   (`ssh cworker`) refused SSH on 2026-10-21; try it first.
5. **Commits** end with the Co-Authored-By line from CLAUDE.md. Never push without the owner's yes.
