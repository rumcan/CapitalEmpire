# The ChatGPT image queue: ready prompts, in order

The owner, 2026-10-28: "use the run.world credits for 3d work. we wont top up, we will use the chat gpt image generator for iamges". RUN is for 3D only now; every 2D picture comes from ChatGPT's image generator. This file is the queue of the next pictures, with each prompt ready to paste and the file name to save it as. The lead puts the saved files into the game.

## How to use it
1. **Start a new ChatGPT chat** for each place and attach the two references first:
   - `art/theme-consistency/references/theme-authoritative.png` (the style);
   - `docs/art/concept/maple-falls-concept.webp` (the colours).
2. **Paste the first prompt** (the run-down, or tier 1) and ask for a **16:9 landscape** picture.
3. **Make the matching version as an edit.** Upload or keep the picture you just made, then paste the second prompt (upgraded, or the next tier). It starts "Keep exactly this viewpoint", so the two line up and the game can swap them.
4. **Save each picture** to `art/theme-consistency/generated/scenes/<slug>/<file>`, the name given under each prompt (PNG, any size about 1536x864 or larger). Tell the lead when a batch is in.
5. **Check before saving:**
   - 1985 only (no phones or modern cars);
   - no real brands or film titles;
   - signs spelt right;
   - the light from the upper right.
   Ask ChatGPT to fix one thing at a time if needed.

The approved look is batch 1 (made on RUN before the switch): `E:/ClaudeTemp/ART-RUN/SCENES-batch1-contact.png`. It is a warm painted illustration with a nostalgic poster feel. The range is called "Maple Falls Driving Range".
