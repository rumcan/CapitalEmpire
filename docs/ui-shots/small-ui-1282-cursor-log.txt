#1282: the map's pointer cursor, checked in the real game (scripts/dev/small-ui-shots.mjs, headless Chrome, one browser, a dev server on a scratch port).
Each section: the computed cursor (getComputedStyle of the map's overlay canvas) over each kind of thing with Select in hand, with a tool in hand and with Walk; then the oracle:
the engine's pick (Game.clickOpensAt) against a REAL mouse click at every point of a grid of the screen: they must agree.
A pick costs a few microseconds (performance.now is coarsened to 100 us here, so the per-call p50/p95 read 0 / 100: use the means).
