# Modern house source views

Eight ordinary 1990s–2020s homes, with eight distinct source-view PNGs each. [index.json](./index.json) records selected native sheets, exact crop rectangles, PNG/RGBA hashes and provenance. [verification.json](./verification.json) records the 64 source pixel checks.

The first 32 PNGs are byte-for-byte copies of the original four-house bundle. The next 32 preserve native RGBA half-cells from the four expansion homes. Bungalow uses normal-v2/yaw8-v2; compact solar home uses normal-v2/yaw8-v1. Duplex and six-flat walk-up use normal-v1/yaw8-v1.

The original 2010s townhouse W correction remains a full 1254px single view; the other sheet cells remain 627px. It has not been resized. [camera-holds.json](./camera-holds.json) keeps camera, cross-view scale and ground-anchor release holds separate. These are source candidates, not certified exact 8-degree artwork or runtime-ready assets. Original native sheets and the earlier bundle/ZIP remain unchanged.
