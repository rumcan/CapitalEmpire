# Additional affordable later-era dwellings

Four proposed technical reference models: a1990sbuff-brick bay bungalow, a2000ssingle-storey duplex, a2010ssmall six-flat walk-up and a2020scompact two-storey gabled solar home. See [brief-index.json](./brief-index.json) for dimensions, fixed openings, source meshes and paired normal/yaw8guides.

These are source geometry and design proposals, not accepted runtime occupancy values or final native painted sprites. No runtime changes, imagegen calls, imports, services, tests, build or commits.
