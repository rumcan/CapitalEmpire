# Fixed-world golf mobile-prop geometry guides

Eight proposed technical world models,16guide sheets and64views. See [compact.json](./compact.json) for generation-ready guide/identity paths and fixed-state instructions, or [index.json](./index.json) for source meshes, dimensions, camera metadata, hashes and provenance.

Each model rotates as one physical object: medical rear stretcher, wheelchairLEFTside ramp, three shuttle bench rows, vending umbrella/wheel/handle/rack layout, exact loaded cargo groups, curved fixed-axis satellite dish and broadcast roof reel/HVAC/aerial. The dish reuses the existing curved-shell helper and includes front/back surfaces, rim, feed tripod and back ribs; it never swivels independently toward a camera.

All16sheets were visually inspected, each model has8distinct technical RGBA view hashes and no geometry clipping. Sizes and clearances are design proposals, not current runtime dimensions, economy, era binding, accessibility certification or final art approval. Technical surfaces are geometry proxies; root native generation uses the inspected identity/style references for final body/material detail. No native imagegen, source image edits, runtime changes, services, tests, build, imports or commits.
